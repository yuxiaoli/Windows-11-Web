# Bounded window usability repair

Date:2026-10-25 UTC

The parent independent QA reported Edge opening offscreen at1180x757. The repair was recorded and pushed first in the existing canonical plan (4472016b4b5e876a7de6bf95faf54b259a12c8d8). Main remains the unmodified upstream cache; no Boot Loader registry or alias change is in scope.

## Implementation

- Replaced random initial coordinates with centered fitted geometry. The original live source was reproduced at about x615/right1355 in an1180px viewport.
- Defined the measured window workspace above the50px taskbar. Normal geometry is controlled and clamped on viewport resize, drag-stop and resize-stop; dimensions/minima also fit narrower viewports.
- Maximized windows fill only the usable workspace, disable drag/resize and restore their saved fitted normal rectangle.
- Close and maximize/restore are accessible named buttons; action buttons cannot initiate titlebar drag. Long titles yield space to controls; Restore icon honors theme color. Original upstream/macOS-Web attribution is retained.
- Kept the existing desktop viewport convention. Mobile-size geometry is checked; a full mobile redesign of the upstream shell is not claimed.
